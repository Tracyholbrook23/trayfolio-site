# Trayfolio

Business website for Trayfolio — Tracy Holbrook's web design & development studio.
Built with [Next.js](https://nextjs.org) (App Router), TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Deploying

This project is connected to Vercel — pushing to `main` on GitHub triggers a deployment.
